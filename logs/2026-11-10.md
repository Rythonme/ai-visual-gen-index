### 已完成

1. **资源清单**：`data/tools.json`，90 条资源 / 7 大分类（生图模型 16、生视频模型 17、生图平台 13、生视频平台 15、工具框架 11、控制增强 8、资源评测 10），其中 50 个 GitHub 仓库可自动追踪热度。该清单是唯一需要人工维护的源文件。
2. **评分算法**：`data/config.json` 公开全部权重。热度分 = Star 规模 45% + Star 增速 20% + 维护活跃度 20% + 社区信号 15%；实用性分 = 易上手/成本许可/输出质量/中文支持/生态文档/硬件效率六维加权；综合分 = 0.45 热度 + 0.55 实用。闭源产品用人工 `heat_baseline`，网站明确标注口径不同。
3. **五类榜单**：综合榜、热度榜、实用榜、上升榜（仅 GitHub 追踪项目）、开源榜（仅开放权重项目）；另按 7 类做分类速览。模型社区与评测榜作为「参考」入口，不参与主榜名次。
4. **每周自动更新**：`scripts/build.py`（零第三方依赖）抓取 GitHub REST API / Hugging Face API 的公开元数据；API 限流时回退读取 GitHub 仓库页面内嵌的 Star/Fork/许可证 JSON（仍只是读一个网页的公开数字，不 clone、不下载权重）；自动重算榜单并生成 `rankings.json`、`docs/data.js`、README 榜单区块、周报、26 周历史快照。`scripts/check_links.py` 校验外链，`scripts/discover.py` 只产出新资源候选（**绝不自动收录**，须人工核实）。
5. **GitHub Actions**：`weekly-update.yml` 每周一 UTC 02:00（北京 10:00）+ 手动 + 清单变更触发，用内置 `GITHUB_TOKEN`，自动提交；`pages.yml` 负责部署 Pages，两条链路解耦。
6. **展示层**：`docs/index.html` 纯静态中文站（五榜切换、搜索、分类/类型/中文筛选、分数条、Star 迷你趋势、官方外链按钮、算法说明、深浅色自适应），无 CDN 依赖，双击即可查看；`docs/kanban.html` + `kanban_data.js` 项目进展看板（改数据文件即刷新）。
7. **文档**：README（方法/周更/部署/声明）、CONTRIBUTING（字段与评分锚点）、LICENSE / LICENSE-DATA、.gitignore、`push_to_github.bat`。
