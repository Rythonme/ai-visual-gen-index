每周自动更新什么？哪些部分需要人工维护？

自动（每周一 10:00 北京时间）：GitHub Actions 读取 GitHub / Hugging Face 公开 API 的元数据（Star、Fork、最近提交、许可证、官方简介、模型 likes 与下载量）→ 按公开算法重算四类榜单 → 自动更新 README 榜单区块、本站数据、周报与 26 周历史快照 → 自动提交并部署网站。全程只读元数据，不下载任何模型或素材。

人工：闭源产品的热度基线、实用性六维评分、新增或下架条目，以及 `scripts/discover.py` 产出的新资源候选清单审核。发现脚本只提候选，绝不自动收录。

兜底：API 限流或网络失败时自动回退到缓存 / 人工基线，并在每张卡片上标注数据来源，保证榜单每周都能生成。
